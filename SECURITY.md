# Security Policy

Do not include credentials, private paths, or other secrets in a report.

## Report a Vulnerability

Use [GitHub Security Advisories](https://github.com/PrestonTseng/skill-delegator/security/advisories/new) to report a vulnerability privately.

Include this information:

- the affected version or commit
- the security impact
- the steps that reproduce the problem
- a proposed correction, if available

Do not open a public issue for an uncorrected vulnerability.

## Supported Version

The latest commit on `main` receives security corrections during the V1 development period.

Read the [threat model](docs/threat-model.md) for security boundaries and non-goals.
