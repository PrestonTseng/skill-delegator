# NORAC — Communications and Personnel (Rules 700–998)

**Full text:** `references/norac-comms-personnel.md`

## When to Use
Radio procedures, electronic device restrictions, or position-specific duties on NORAC territory. For Form D/DCS see `railroad-norac-authority`. For signal rules see `railroad-norac-signals`.

| Rule | Topic |
|------|-------|
| 701 | Train radio — working radio on lead engine + redundant means required |
| 702 | Track cars — working radio required; lone workers within hearing range |
| 703 | Radio test before work; defective radio: remove, notify Dispatcher |
| 705 | All safety transmissions must be repeated; unclear transmission must not be acted upon |
| 707 | Absolute priority to emergency communications |
| 708 | Code words: ROGER / OVER / OUT / EMERGENCY ×3 |
| 711 | Radio in place of hand signals — job briefing; stop at ½ specified distance if no further instructions |
| 712 | Dispatchers/Operators must NOT advise signal aspect to crews |
| 715 | Calls regularly recorded; audible beep indicates recording |
| 716 | Personal electronic devices — off and stored out of sight during duty |
| 800 | Track car — qualified on car type and territory before assignment |
| 802 | Multiple track cars under one Form D; each Foreman/Driver holds own copy |
| 803 | Track car must not follow another movement into DCS territory until that movement reports clear |
| 806 | Track car — ≤15 MPH over crossings; stop unless warning ≥20 sec or gates horizontal |
| 807 | Track car — must not enter/leave interlocking or CP without proceed signal or verbal permission |
| 902 | Dispatcher — charge of train movements; record blocking devices immediately (never from memory) |
| 903 | Dispatcher transfer — complete record; relieving Dispatcher signs in outgoing's presence |
| 905 | Blocking device log format; must not remove until protection no longer required |

| 941 | Conductor — general charge of train |

| 952 | Engineer — must be qualified on engine type |
| 956 | Engineer — responsible for all signal observation and speed control |
| 958 | Engineer — if visibility doubtful: regulate speed immediately |
| 961 | Engineer — must carry current Certification Card |
| 981 | Yardmaster — charge of yard (except main tracks and controlled sidings) |
| 997 | Track Car Foreman — responsible for movement, safety, and care of track cars |
| 998 | Track Foreman — responsible for track condition; apply protective action immediately |
