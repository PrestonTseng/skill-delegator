# NORAC — Movement of Trains (Rules 80–142)

## When to Use
Questions about train speeds, switch operations, work protection (Form D, Foul Time), emergency
procedures, flag distances, unattended equipment, or Train Coordination on NORAC territory.
Full rule text in `references/norac-train-movement.md`. For Form D structure see
`railroad-norac-authority`. For signal system rules see `railroad-norac-signals`.

---

## Key Rules Index

| Rule(s) | Topic | Key Points |
|---------|-------|------------|
| 80 | Restricted Speed | ≤20 MPH (≤15 in interlocking); stop within ½ range of vision of obstruction/bad switch/Stop signal |
| 90 | Delay of Trains | Promptly advise Dispatcher of any delay or speed restriction |
| 91 | Starting | Must have Conductor's hand signal, communicating signal, or verbal permission |
| 92 | Departure Time | Must not leave ahead of schedule without authority |
| 93 | Yard Limits | Movements on main track by Dispatcher verbal permission; Restricted Speed unless signal better than Approach |
| 94 | Signal Responsibilities | Call each signal aloud; reconcile discrepancy or stop; 2-mile advance notice for restrictions |
| 96–99 | Sidings / Running Tracks / Non-signaled / Excepted | Restricted Speed; ≤10 MPH on FRA Excepted Track |
| 100 | Coupling/Switching | Coupling ≤4 MPH; stretch slack before shoving; two crews require job briefing |
| 103 | Running Switches | Never with hazmat, passengers, livestock, or toward trestle/building |
| 104 | Hand-Operated Switches | Visually verify lining; return to normal and lock when not in use; ≤15 MPH through hand-op switch; dual-control requires Dispatcher permission |
| 105–106 | Spring / Semi-Automatic Switches | Trailing without lining OK if no conflict; lever not unlatched until points complete auto-movement |
| 108 | Unattended Engine | Air + hand brakes applied; reverser removed; traction power disabled |
| 116 | Train from Other Than Leading End | Qualified employee on lead; communication maintained; ≤30 MPH |
| 123 | Dead Man / Alerter Failure | Employee must occupy cab with Engineer immediately; repair by next day inspection |
| 125 | Pilot Requirements | Required when Conductor/Engineer qualification expired or never qualified on territory |
| 130 | Flag Protection | Distance by track speed: ≤20 MPH=¼mi, 21–30=½mi, 31–40=1mi, 41–90=1½mi, ≥91=2mi |
| 132 | Work Location Protection | ABS/DCS/Interlocking: Form D line 4 or 5 for track foul/disturb; Foul Time for non-disturbing work |
| 133 | Track Out of Service (Form D line 4/13) | Signals at Stop + blocking devices applied; ABS rules suspended within limits |
| 135 | Working Limits (Form D line 5) | Signs required; Dispatcher permission before entry; ≤40 MPH passenger / ≤25 MPH freight |
| 136 | Emergency Stop | Broadcast emergency radio immediately; flag both directions; other trains at Restricted Speed 1 mi each side |
| 137 | Assisting Disabled Train | Form D lines 8+9 required for opposing movements; flag ¼ mi toward assisting train |
| 138 | Highway Crossing Warning | Malfunction without flagger: stop or ≤15 MPH; 6 conditions require 20-second gate verification |
| 139 | Cars Left on Main Track | Dispatcher authorization; blocking devices at entry signals |
| 140 | Foul Time | Dispatcher only; includes track + limits + time; confirm no conflicting movements first |
| 141–142 | Inaccessible Track / Train Coordination | Switch/derail secured + tagged; RWIC must release working limits before train relinquishes authority |
