# NORAC — Signals, ABS, CSS, PTC, Interlocking

**Full text:** `references/norac-signals.md`

## When to Use
Signal aspects/indications, ABS block rules, cab signal conformity/failure, PTC, or interlocking movement on NORAC territory. For Form D/DCS see `railroad-norac-authority`. For general movement see `railroad-norac-train-movement`.

---

## Speed Definitions

| Speed | Definition |
|-------|-----------|
| Normal | Maximum authorized |
| Limited | ≤45 MPH |
| Medium | ≤30 MPH |
| Slow | ≤15 MPH |
| Restricted | ≤20 MPH; stop within ½ visible distance of any train/obstruction/Stop signal |
