# CROR — General Rules, Definitions, Signals (Rules A–125)

## When to Use
CROR terminology, employee obligations, timetable rules, hand/whistle signals, blue signal
protection, or general operating conduct. Full rule text in `references/cror-general-rules.md`.
For signal aspects see `railroad-cror-signals`. For movement authority see `railroad-cror-train-movement`.

## Speed Definitions

| Speed | Definition |
|-------|-----------|
| LIMITED | ≤45 MPH; stop within ½ range of vision |
| MEDIUM | ≤30 MPH; stop within ½ range of vision |
| REDUCED | ≤25 MPH; stop within ½ range of vision |
| SLOW | ≤15 MPH; stop short of train/obstruction/misaligned switch |
| DIVERGING | ≤15 MPH through turnouts; stop short of obstruction (may vary by SI) |
| RESTRICTED | ≤15 MPH; stop within ½ range of vision; stop short of train/obstruction/misaligned switch |

## Key Definitions

| Term | Meaning |
|------|---------|
| RTC | Rail Traffic Controller — the dispatcher |
| OCS | Occupancy Control System — written permission-based authority system |
| TOP | Track Occupancy Permit — RTC-issued authority for track units/work crews |
| CTC | Centralized Traffic Control — block signals governed by RTC |
| ABS | Automatic Block Signal System — governs block occupancy, not main track authority |
| ECM | Electronic Communications Method — computer terminal or fax for authorities |
| ATDS | Advanced Train Dispatching System — computer-issued movement authorities |
| TU | Track Unit — maintenance/inspection vehicle (not a train) |

## General Rules — Critical Points

| Rule | Key Requirement |
|------|----------------|
| A | Carry rulebook + documents while on duty; re-examine every **3 years**; seek clarification when in doubt |
| A(xi) | **Sleeping prohibited**. Personal entertainment devices prohibited in operating cab |
| A(xii) | Cellular phones prohibited when railway radio is available; all radio rules apply if cell used |
| C | Expect movement on any track at any time; do not entrain/detrain above **4 MPH** except emergency |
| G | Intoxicants/narcotics **prohibited** on duty; any drug impairing safety prohibited even if prescribed |
| J | Illegible ECM transmissions must not be acted upon; report and request retransmission |
| K | "In writing" = copy + repeat back to sender for confirmation |

## Time and Timetables (Rules 1–9)

- **Rule 1:** 24-hour system; midnight = 2359 or 0001.
- **Rule 2:** Watch variation ≤30 seconds/24 hours; compare with crew members at start of work.
- **Rule 4:** Time change notice: ≥72 hours by bulletin; ≥24 hours by GBO (GBO continues 6 days after).

## Whistle Signals (Rule 14)

| Signal | Meaning |
|--------|---------|
| — (1 long) | Apply brakes / stop |
| — — (2 longs) | Release brakes / proceed |
| — — — (3 longs) | Back up |
| — — — — (4 longs) | Call for signal |
| ● — (short + long) | Flagman: return to train |
| — — ● — | Approaching grade crossing |
| Any series of shorts | Emergency |

## Critical Signal Rules

- **Rule 26 (Blue Signal):** Equipment must not be moved while blue signals applied. Only the applying employee may remove it. Equipment with blue signals must not be connected to other equipment unless employees are clear.
- **Rule 27:** Signal imperfectly displayed → govern as **most restrictive** indication possible; notify proper authority.
- **Rule 34:** Positively identify each signal before passing. If signal changes after identification but before leading end passes: comply with **most restrictive** indication displayed. Cannot identify signal → **stop**.

---

## General Operating Key Points

- **Rule 82:** Movement must not proceed beyond limits of authority.
- **Rule 109:** Before moving — verify brakes released, switches lined, all crew in safe positions.
- **Rule 122:** All movement authorities by radio must be **repeated word-for-word** and acknowledged before being acted upon.
- **Rule 123.1:** Radio in place of hand signals: job briefing first; specify distance; stop at ½ specified distance if no further instructions.
- **Rule 125:** Emergency: notify endangered movements first by quickest available means.
